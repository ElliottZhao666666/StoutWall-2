# 界面重构候选方案

日期：2026-11-26。正式程序继续使用 C++17、Win32、Direct2D/DirectWrite，本轮交付三套可交互设计原型，尚未替换正式界面。原型中的切图、收藏、设置、主题参数和大图操作仅在原型内演示。

## 三套布局

| 方案 | 主要布局 | 适合场景 | 取舍 |
|---|---|---|---|
| 清简侧栏 | 左侧固定导航，右侧当前壁纸和信息，底部常用操作 | 当前壁纸、图库、收藏、设置之间频繁切换 | 入口直观，窗口占用较大；侧栏窄窗时需要收起 |
| 轻巧单窗 | 顶部三个短标签，中央一张大图，底部切换、暂停、保存、应用 | 日常查看和更换壁纸 | 窗口紧凑、重点明确；复杂参数需放入设置面板 |
| 图库工作台 | 缩略图网格与右侧详情，顶部筛选、主题导出 | 收藏整理、挑图、主题导出 | 多图比较方便；需要按可见区域加载缩略图 |

建议以“轻巧单窗”作为默认主窗口，以“图库工作台”作为图库管理窗口。两者共用字体、图标、配色和操作规范。“清简侧栏”适合以后功能入口增多时采用。

原型用 HTML 表达布局，使用同一套图库风景样张，并提供浅色/深色配色、圆角与留白调节；它不意味着为正式程序引入浏览器运行时。窄至 320 像素的原型也能排布，正式桌面窗口的最小尺寸应在实施时按 DPI 与键盘可达性确定。

## 功能安排

- 当前壁纸：图片、日期、标题、地点和版权，上一张/下一张、暂停、收藏、保存原图、设为壁纸；双击或明确的大图按钮进入查看器。
- 图库：全部/收藏筛选，按日期排序，选择后看详情；应用、导出、删除保留原有确认和错误处理。原型的少量样张不代表实际图库数据。
- 设置：来源、尺寸、轮播模式、间隔、顺序/随机、自动保存、图库位置及软件信息。低频设置不挤占主窗口。
- 主题导出：主题名、全部/收藏、系统格式、尺寸、间隔、顺序、样式和颜色采用独立表单。原型展示主要参数，正式迁移须保留现有完整参数。
- 七日页和手动主题选择维持已确认的暂缓范围。

## 在现有技术栈上的实施方法

1. 保留 `ProductBackend` / `TaskRunner` 的动作、取消及串行图库访问，只替换布局、绘制与交互绑定。Win32 原生文件对话框、菜单与键盘消息处理继续使用。
2. 用 Direct2D 绘制背景、分隔线、按钮状态和图片，DirectWrite 排版；优先普通实色背景、小圆角、清晰层次。Win7 基础样式不依赖 Mica、WinUI 或系统新材质。
3. 布局以 DIP 计算，重算 DPI、字号和点击区域；统一焦点提示、Tab 顺序、快捷键、禁用状态和高对比度配色。文字与图标按钮均提供可读名称。
4. 当前壁纸预览上限 1920×1080，图库网格按实际缩略图尺寸生成更小缓存；只加载可见项及少量邻近项。压缩图缓存、解码像素和 D2D 位图分别设上限，隐藏窗口按需释放资源。
5. 保留已完成的“图片不变就不解码”和 D2D 位图复用。窗口重排、收藏状态变化、预览模式变化只更新需要的区域。
6. 后台读取和解码完成后只投递仍与当前所选项匹配的结果；切换尺寸、关闭窗口、退出均可取消在途任务。
7. 动效仅用于短暂状态反馈，允许关闭；不以复杂透明层、阴影或持续重绘增加常驻开销。

## 原型验收与实施顺序

本机浏览器已检查三种布局、切换样张、设置面板、主题参数面板及工作台窄屏排布。交互原型在本次会话中直接展示；正式界面仍保留现有业务入口。

现有正式界面的选项卡与部分图标控件，辅助功能名称和选中状态不完整，本机自动化需借助画面定位。正式重构应补齐这些语义，避免仅靠图形判断当前页面或操作状态。

落地时先做主窗口和设置，再做图库及大图，最后迁移完整主题表单与键盘/无障碍支持。每一步使用独立数据目录，对照已有保存、导出、轮播、退出与异常回滚验收；Win7 实机验收留后续。
