# 1.1.0 原版转制基线

## 依据与边界

权威依据为上级解包工程的 `src/` 窗口 XML、窗口程序集、普通程序集和 `ecom/` 模块源码；`StoutWall_ReBuild_2_Test` 中的 Demo 只提供过往试验记录，不定义产品窗口或功能。原始版本字符串 `V1.1.0.2509`、九个窗口原尺寸、文本、资源和窗口入口应保留。

运行目标为 32 位 Windows 7 SP1 及以上。主程序与新增 DLL 静态链接 MSVC CRT（`/MT`），系统 API 仍由 Windows 正常提供。`gallery.dll` 为既有 x86 易语言静态编译 DLL，调用需在专用图库线程中串行完成；接口文字走系统 ANSI 代码页，无法无损转换的字段必须明确报错。

唯一允许的旧图库替代路径是通过 `gallery.dll`。初始化沿用 `GalleryBase.EDT` 与 7za 解包到用户配置指定的图库位置；不得用 `StoutWall.cfg` 中原安装目录作测试库。网络下载、配置、Windows 壁纸、主题包分别走静态 CRT 的后端 DLL；UI 线程只处理消息和绘制。

## 后台线程约束

- UI 主线程创建/销毁窗口、处理输入和 Direct2D 绘制。
- 一个持久工作线程按队列处理慢操作和所有图库 DLL 调用：下载/导入/读取/修改/导出/删除/切库均不阻塞消息泵。图库会话禁止跨线程，切库前必须关闭当前会话。
- 网络 DLL 的 WinHTTP 请求设定 TLS 1.2、超时与取消句柄。配置、系统壁纸和归档 API 在任务线程调用；进度/结果用窗口消息回 UI。
- 线程退出先停止计时器与提交，等待进行中的有界操作结束，关闭图库，再释放 DLL。不得在 UI 事件处理器里直接运行 7za/cabarc 或网络请求。

## 明确的旧版边界

- 用户要求自启动只留界面开关：不读、不写、不修复注册表 Run、计划任务或启动文件。配置里的旧 `AutoRun` 值也不用于决定界面状态。
- 用 `SystemParametersInfo(SPI_SETDESKWALLPAPER)` 应用选中图片；不向 Windows 系统目录写 BMP。
- 原版缺失的七日壁纸、自选主题壁纸等业务逻辑不补造；保留其窗口、控件、原始空状态。
- Gallery 字段固定容量不能靠静默截断规避；导入失败显示原始错误并允许重试。
- 现有默认运行配置若指向真实安装库，严禁复制到本机测试输出目录。
