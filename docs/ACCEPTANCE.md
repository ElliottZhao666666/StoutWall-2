## 测试安全条件

- 仅使用一次性临时配置、测试输出目录及独立图库副本；不得使用 `StoutWall.cfg` 指向的真实安装库或覆盖共享夹具。
- 默认保持 `--allow-wallpaper` 关闭，不在通常验收中应用系统壁纸；主题包只生成和检查，不安装。
- 自启动边界不做机器级测试：不读取、枚举、写入或删除注册表 Run、计划任务及启动文件。
- 本轮证据：`tools/verify_product.ps1` 两轮 GUI 验证通过；`tools/run_backend_integration_test.cmd` 后端集成验证通过；`build.cmd` 正式构建通过。上述结果来自本机 Windows 环境，Win7 SP1 仍需按同一脚本做补充采样。
- 自启动和真实桌面壁纸均保持禁用边界；测试没有打开或修改旧版程序的系统启动配置。
